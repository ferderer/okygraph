# 0040. Okygraph: token-based transpilation before compilation via Maven plugin

## Context and Problem Statement

Okygraph is meant to be a fast, dependency-free template engine built on the Maven toolchain.

## Considered Options

* Okygraph: token-based transpilation before compilation via Maven plugin (chosen)
* Thymeleaf
* JSP
* JTE

## Decision Outcome

Chosen option: Templates are written as methods in Java classes (HTML in backticks, expressions in `{...}`, Java code in backticks). An okygraph-maven-plugin tokenizes the file into Java/HTML tokens and transpiles it to plain Java before Java compilation; Maven handles the rest. Validation of expressions remains with the Java compiler, and the transpiled file can be inspected. The generated code needs nothing beyond the application's own framework; the base class is generated by the plugin (ADR-0104).

Rationale: No reinvention of type checking and classpath resolution; the generated code is ordinary Java that can be read and debugged; no template engine at runtime.

### Options not chosen

* **Thymeleaf** — Complex and slow.
* **JSP** — Outdated, cumbersome, not fast.
* **JTE** — Good, but not extensible and faster to build ourselves.
